# 🃏 Memória - GameHub

Jogo de memória onde você encontra pares de cartas iguais!

## 🎮 Funcionalidades

### Níveis de Dificuldade
- **Fácil**: 4x3 (6 pares)
- **Médio**: 4x4 (8 pares)
- **Difícil**: 6x4 (12 pares)

### Recursos
- Timer para controlar o tempo
- Contador de movimentos
- Sistema de estrelas (1-3)
- Animações de virar cartas
- Efeitos sonoros
- Confetti na vitória
- Pré-visualização das cartas no início

## 🎯 Controles

- **Clique**: Virar carta
- **Botão INICIAR**: Começar o jogo
- **Botão RESETAR**: Reiniciar

## ⭐ Sistema de Estrelas

- **3 Estrelas**: Menos de 1.5x o número de pares
- **2 Estrelas**: Menos de 2x o número de pares
- **1 Estrela**: Mais que 2x o número de pares

## 📁 Arquivos

- `memory.html` - Jogo principal

## 🚀 Como Jogar

1. Abra `memory.html` no navegador
2. Escolha a dificuldade
3. Clique em "INICIAR"
4. Memorize a posição das cartas
5. Encontre todos os pares!

## 🎨 Visual

- Design neon moderno
- Animação 3D de virar cartas
