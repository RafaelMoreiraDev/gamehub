# 🏓 Pong - GameHub

O clássico jogo de tênis de mesa implementado com HTML5 Canvas.

## 🎮 Funcionalidades

### Modos de Jogo
- **VS CPU**: Jogue contra a inteligência artificial
- **2 Jogadores**: Jogue com um amigo no mesmo computador

### Dificuldades
- **Fácil**: CPU mais lenta, bola mais devagar
- **Médio**: CPU moderada, bola rápida
- **Difícil**: CPU rápida e precisa, bola muito rápida

### Recursos Visuais
- Efeitos de glow nas raquetes e bola
- Partículas ao marcar ponto
- Animações suaves
- Design neon moderno
- Screen shake ao marcar

### Efeitos Sonoros
- Som ao rebater na raquete
- Som ao marcar ponto
- Som de vitória

## 🎯 Controles

### Jogador 1
- **W**: Mover para cima
- **S**: Mover para baixo

### Jogador 2 (modo 2P)
- **↑**: Mover para cima
- **↓**: Mover para baixo

### Geral
- **Espaço**: Iniciar jogo

## 🏆 Regras

- Primeiro a marcar **5 pontos** vence
- A bola acelera a cada rebote
- O ângulo de rebote depende de onde na raquete a bola acertou

## 📁 Arquivos

- `pong.html` - Jogo principal (HTML + CSS + JS)

## 🚀 Como Jogar

1. Abra `pong.html` no navegador
2. Escolha o modo de jogo (VS CPU ou 2 Jogadores)
3. Selecione a dificuldade (apenas no modo VS CPU)
4. Clique em "INICIAR" ou pressione Espaço
5. Use as teclas para mover a raquete
6. Marque 5 pontos para vencer!

## ⚙️ Tecnologias

- HTML5 Canvas
- CSS3 com gradientes e animações
- JavaScript vanilla
- Web Audio API (sons)
